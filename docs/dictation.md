# 单词听写

路径：`/ielts/dictation`。维持学习站的黑白主题、字体与正常文档流页脚，练习区无动画。

五本词书分别包含机经听力答案词414条、易错词244条、地图题核心词212条、P1号码与地址50条、九分学长听力词表1059条。同书重复词合并，跨书词共享录音，共1881个本地MP3。新词书来自用户提供的“九分学长词表_剔除已有词汇.xlsx”，保持顺序和原词条，保留认可的英美拼写、日期与数字写法；编号逐位读，姓名补充拼读。未改变源Excel或原有录音。P1第二版默认0.9倍速，与普通词书速度独立保存；局部double/triple读法延长约25%，全部12条地址补齐街道名称逐词拼读。50条新版录音同步到本地项目，旧版已备份。

支持分组、乱序、倍速、音量、重复播放、答题字号、显示答案、正确自动提交、错后改正、连续听写、错词循环、错词复习、清空错词、全屏与快捷键。连续模式在录音完成全部指定遍数后等待答题间隔，再检查；启用“错后改对才继续”时错误会停止自动推进。错词循环要求曾答错的词连续正确两次，首次作答正确率不会被复习次数稀释。

页面不接入云发音、麦克风、账号或答题上传，不发送分析事件。浏览器仅存白名单设置及错词ID，不存用户输入、录音、身份信息或凭证。异常和禁用本地存储不阻止练习。所有用户输入与反馈使用表单值或`textContent`，不进行HTML渲染。切词、结束练习、离开页面和隐藏标签页会取消等待任务或停止播放。

录音使用Piper Cori high英式女声，在本地合成。模型来自公开LibriVox数据；模型卡：https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_GB/cori/high/MODEL_CARD 。网站不嵌入Piper运行时。MP3为44.1kHz单声道、128kbps。人工逐词发音审核不在机器解码检查的保证范围内。

`scripts/import-dictation-recordings.mjs`以原词汇清单、P1清单及音频目录为参数，可追加九分学长录音清单作为第四参数。逐文件核对SHA-256、生成词书索引，拒绝覆盖不匹配的文件；不上传、不部署。

检查使用现有类型检查、96项测试、生产构建、构建校验、隐私扫描与生产依赖审计。浏览器验证覆盖词书、真实MP3、认可写法批改、错词保存与复习、P1过滤、重复/倍速、自动提交、两次正确循环、连续听写与退出、窄屏、深色主题、键盘及网络/控制台。可使用`PLAYWRIGHT_MODULE`指定已安装的Playwright模块，`CHROME_EXECUTABLE`指定隔离测试浏览器；`scripts/verify-dictation-browser.mjs`默认执行完整流程。
